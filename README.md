# Smart Fitness & Diet Management System

A web application that helps users manage their fitness activities, diet plans, and overall health in one place.

## Features
- Secure user registration and login
- BMI calculator
- Customized diet plan management
- Workout activity logging
- Weekly progress tracking

## Tech Stack
- Front end: HTML, CSS, JavaScript
- Back end: Python, Flask
- Database: SQLite

## How to Run
1. Install Python from python.org
2. Open a terminal in the SmartDietManagementSystem folder
3. Install Flask: `pip install flask`
4. Run the app: `python app.py`
5. Open http://127.0.0.1:5000 in your browser
